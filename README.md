# Peter Drury 

This is a Google Chat bot that hits the football_data.org API to plug in match scores right into your chat space. 

Tech Stack: Python, Github Actions, REST API

It was actually really fun to make, considering it was my first real project. It features state-diffing logic to prevent spam, rate limiting to prevent broke-ness and was deployed as a serverless cron job that resulted in 350+ failed runs and a mess of github issues. 

You can also change it to any competition in a matter of seconds. As long as its the Premier League. Peter Drury does not care about Ligue 1. Nobody cares about Ligue 1.
